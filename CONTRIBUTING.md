# Contributing

StreamSnipe is built by [Fanclan.io](https://fanclan.io) and maintained by [zerodayprime](https://github.com/zerodayprime).

Use a feature branch and pull request. Describe the resulting user behavior and include verification. Preserve accessibility, keyboard support, responsive layouts, and both themes. Keep one dashboard implementation for hosted and local builds.

Run type checks, unit/browser tests, and both builds. Use synthetic fixtures in tests and screenshots. Pairing and media transport changes require compatibility tests with supported companion releases.

Never upload recordings, databases, credentials, or private paths. Do not add cloud media endpoints or third-party dashboard telemetry. Engine changes belong in [StreamSnipe Companion](https://github.com/Fanclan/StreamSnipe-Companion).
