# Security policy

Use GitHub private vulnerability reporting through this repository's Security tab when available. Otherwise request a private channel in a minimal issue without sensitive details.

The portal must never receive or relay user media. Report suspected leaks, unsafe pairing, origin-validation problems, credential exposure, or untrusted-script execution privately. Do not attach recordings, signed media URLs, tokens, databases, or unredacted logs.

The current supported release is the primary security-fix target. Preview deployments are not trusted companion origins by default. Pairing should always be an explicit action approved on the user's own device.
